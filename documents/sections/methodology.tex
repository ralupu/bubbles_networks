\section{Methodology}

\subsection{Bubble-overlap network construction}

At each date $t$, we construct a directed graph where nodes represent firms and edges represent temporally ordered bubble overlap.
An edge $i \rightarrow j$ is added when firm $i$ is in an active bubble and firm $j$ enters a bubble later within that overlap period.
Node features include normalized $\Delta$CoVaR and bubble duration (days), with optional eigenvector centrality.

\subsection{Temporal graphs and centrality analytics}

The pipeline constructs a time series of PyTorch Geometric graph snapshots (\texttt{results/temporal\_graphs.pkl}).
Centrality measures (degree, betweenness, eigenvector) are computed per snapshot and visualized as:
\begin{itemize}
  \item \texttt{documents/figures/fig\_centrality\_dynamics.png}
  \item \texttt{documents/figures/fig\_centrality\_heatmap.png}
\end{itemize}

\subsection{Validation and diagnostics}

We export baseline diagnostics for both the aggregate overlap network and the temporal snapshot graphs.
These checks include: node/edge counts, density, weakly connected components, and edge-weight summaries.
We also report top nodes by degree (and weighted degree) and export:
\begin{itemize}
  \item a summary table (\texttt{documents/tables/table\_network\_summary.tex})
  \item degree distributions (\texttt{documents/figures/fig\_degree\_distributions.png})
\end{itemize}

For temporal centrality validation, we enforce strictly increasing snapshot dates and export per-node summary statistics (mean/std over time) plus a top-nodes table and a time-series figure for the top nodes:
\begin{itemize}
  \item \texttt{documents/tables/table\_centrality\_summary.tex}
  \item \texttt{documents/figures/fig\_centrality\_top\_nodes.png}
\end{itemize}

\subsection{FRM dynamic network (quantile regression)}

As a second systemic-risk lens, we construct dynamic FRM networks from rolling-window quantile regression on firm returns.
Let $r_j(t)$ denote the return of firm $j$ at time $t$.
For each target firm $j$ and each evaluation date $t$, we fit a quantile regression at quantile $q$ over a rolling window of length $W$:
\begin{equation}
  r_j(\tau) = \alpha_j(t) + \sum_{i \neq j} \beta_{i \rightarrow j}(t) \, r_i(\tau) + \varepsilon_j(\tau), \qquad \tau \in \{t-W,\dots,t\}.
\end{equation}
We interpret the coefficient $\beta_{i \rightarrow j}(t)$ as a directed dependency from $i$ to $j$ in the tail of the return distribution (at quantile $q$).
Edges are thresholded using a simple, publishable rule: we keep the top-$K$ incoming edges per target node $j$ ranked by $|\beta|$ (with $K=5$ in the paper builds), and define edge weights as $|\beta|$.

The FRM network is written as a sequence of PyTorch Geometric snapshots under \texttt{results/frm/} (artifacts) and paper-facing summaries/figures are exported to \texttt{documents/} when the FRM build flag is enabled.

\subsection{Time-aware Bubble vs FRM similarity metrics}

To compare whether the bubble-overlap network and FRM network encode similar systemic-risk structure over time, we compute snapshot-level similarity metrics after aligning dates.
For each bubble snapshot date $t$, we align to the nearest prior FRM snapshot date $t' \le t$ (and drop $t$ if no such $t'$ exists).

On each aligned pair $(t,t')$, we report: (i) rank similarity of node importance (Spearman correlation between eigenvector centrality ranks), (ii) top-$k$ node set overlap (Jaccard for $k \in \{5,10\}$), and (iii) edge-set similarity (Jaccard overlap between the top-$M$ directed edges by $|w|$, with $M=50$, and correlation of $|w|$ on the intersection when available).
In \texttt{minimal} builds, FRM is intentionally restricted for runtime (e.g., first $N=20$ firms and a short date range); the bubble temporal graphs are restricted to the same firm set for a fair comparison.

\subsection{TGNN forecasting (optional)}

We provide a TGNN forecasting pipeline (GConvGRU/A3TGCN/EvolveGCN variants) that predicts next-step eigenvector centrality targets.
This module is optional and can be enabled for full builds.
