\section{Robustness}

We assess how sensitive the baseline overlap network is to the exact edge-construction choices.
The goal is not to exhaustively search the parameter space, but to confirm that key diagnostics and the identity of highly central firms are not an artifact of a single, hard-coded definition.

\subsection{Overlap-network sensitivity grid (M4-lite)}

We run a small grid over two design choices:
(i) a minimum overlap threshold (min overlap days in $\{0,5,10\}$), and
(ii) an edge direction rule.
The baseline rule (\texttt{start\_lead}) directs edges from earlier bubble start to later bubble start whenever bubble episodes overlap.
An alternative rule (\texttt{overlap\_undirected\_then\_direct}) first aggregates overlaps for each firm pair and then directs the edge using the average lead/lag of bubble start dates across overlapping episodes.

Table~\ref{tab:robustness_summary} summarizes how global network diagnostics and the stability of the top-10 nodes (by aggregate centrality) vary across configurations.
Figure~\ref{fig:robustness_heatmap} visualizes the top-10 stability as a heatmap (Jaccard overlap relative to the baseline configuration).

\subsection{FRM sensitivity (minimal)}

We include a minimal FRM sensitivity check over the rolling window length ($W \in \{60,120\}$) while keeping the quantile fixed ($q=0.05$) and using a top-$K$ incoming edge rule (with $K=5$).
This is designed to be fast enough for routine runs while highlighting whether the FRM structure is overly dependent on a single window choice.
